# 影片番號命名規則

## 標準格式

`番號_畫質.原副檔名`

例如：`ABC-123_480p.mp4`、`ABC-123_720p.mkv`、`ABC-123_1080p.mp4`。

- 番號中的英文字母統一大寫；保留數字段的前導零。番號內使用半形連字號，例如 `ABC-007`。
- 番號與畫質之間只用一個半形底線 `_`，不用連字號或空白。
- 畫質使用小寫 `p`，例如 `480p`、`720p`、`1080p`。只有可明確辨認為畫質的獨立數字標記才可補上 `p`；不能把作品數字、日期或流水號當成畫質。
- 保留原副檔名與所在資料夾；清除已確認不屬於番號、畫質或分卷必要資訊的描述與網站流水號。
- 畫質缺失時使用 `番號.原副檔名`，不猜畫質。多個畫質標記互相矛盾時，保留原名並列入待確認。
- 多分卷內容使用 `番號_CD2_畫質.原副檔名` 等保留卷次的格式。卷次有歧義時先詢問，不合併分卷。

## 番號辨識界線

只用可信、明確的番號候選產生預覽。一般英文單字接 `360p`、`480p`、`720p` 或 `1080p`，不構成番號；相機命名如 `IMG_0045`、日期與下載流水號也不能自動視為番號。初版 inventory 的 work_id 是寬鬆候選，必須人工或更嚴格的規則複核。

找不到可信番號時保留原名，不能編造番號，也不為了補齊番號而自動開啟影片或將私人檔名傳給網路服務。`._` 開頭的 macOS 輔助檔不算影片，不納入獨立改名候選。

## 衝突與執行

- 同一番號及畫質的多個檔案不能互相覆寫，也不能僅憑名稱判為重複；列出衝突，保留原名待確認。
- 已符合格式者不重複改名。
- 改名預覽逐項記錄原路徑、目標路徑、番號與畫質依據；經確認後才執行，並保存復原對照。
- 若原影片有 `._` 伴隨檔或字幕，先檢查關聯並在計畫中列出處理方式，不把本規則當成刪除伴隨檔的授權。

## 現有程式能力

此文件是 Skill 決策規則，不代表新增了改名執行器。`scripts/plan.py` 仍是依作品分資料夾的預覽，不能用它宣稱完成本規則的同目錄改名。需要同目錄改名時另產生可審核的預覽及復原紀錄，沿用 SKILL.md 的執行授權界線。
